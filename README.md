# 📊 Amazon Sales Analysis using Python & Power BI

## 📌 Project Overview

This project analyzes Amazon sales data to uncover valuable business insights using **Python** and **Power BI**. It covers the complete data analytics workflow, including data cleaning, exploratory data analysis (EDA), data visualization, and interactive dashboard creation.

The objective of this project is to understand sales performance, customer purchasing behavior, product trends, and regional sales distribution to support data-driven business decisions.

---

## 🎯 Objectives

- Clean and preprocess raw sales data.
- Analyze sales performance using Python.
- Identify trends and patterns in customer purchases.
- Visualize key business metrics.
- Build an interactive Power BI dashboard.
- Generate actionable business insights.

---

## 📂 Dataset Information

**Dataset:** Amazon Sale Report

The dataset contains Amazon order information, including:

- Order ID
- Order Date
- Order Status
- Product Category
- Product Size
- Quantity Sold
- Sales Amount
- Fulfillment Method
- Courier Status
- Shipping City
- Shipping State
- Shipping Country
- Sales Channel
- B2B/B2C Orders

## 🚀 How to Run the Project

1. Clone this repository.

```bash
git clone https://github.com/your-username/Amazon-Sales-Analysis.git
```

2. Install the required libraries.

```bash
pip install pandas numpy matplotlib seaborn
```

3. Open the notebook in **Google Colab** or **Jupyter Notebook**.

4. Run all cells.

5. Open `Amazon_Sales_Dashboard.pbix` using **Power BI Desktop**.
